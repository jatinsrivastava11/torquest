# Torquest

**Spot cars in the wild. Build your collection.**

Torquest is an installable web app for car enthusiasts. Photograph a car you see, add it to your
collection, open it as a 3D model, look inside its engine, and earn points for how rare it is.

> **Status:** early. Project skeleton, collaboration setup and the 3D engine studio prototype.

- What we're building: [team/VISION.md](team/VISION.md)
- How to contribute (humans and AI agents): [AGENTS.md](AGENTS.md)
- Setting up as a new teammate: [team/ONBOARDING.md](team/ONBOARDING.md)

```sh
npm install
npm run dev      # http://localhost:3000
npm run check    # typecheck + tests + build
```
